# Adaptive Noise Cancellation using MATLAB

An Adaptive Noise Cancellation system developed using MATLAB to reduce unwanted noise from a signal using an adaptive filter and the Least Mean Squares (LMS) algorithm.

## 🚀 Features

- 🎧 Generates a clean speech-like signal
- 🔊 Generates random noise using Gaussian noise
- ➕ Adds noise to the original signal
- ⚙️ Implements an LMS adaptive filter
- 📉 Reduces unwanted noise
- 📊 Displays time-domain signal plots
- 📈 Displays spectrograms
- 🔊 Plays original, noisy, and filtered signals
- 💾 Saves audio signals as WAV files

## 🛠️ Technologies Used

- **MATLAB**
- **Digital Signal Processing (DSP)**
- **Adaptive Filtering**
- **LMS (Least Mean Squares) Algorithm**
- **Signal Processing**
